# 排版演示：让每周的反馈接着用

下面用一个假设任务演示：让 AI 每周跟踪一个行业，看看上周的反馈能否接着用。

## 第一周，先把判断讲清楚

第一周，它找来二十条消息。你删掉一半，告诉它哪些只是厂商宣传，哪些值得继续追问。

**反馈有了具体对象**：保留哪一条，删掉哪一条，理由是什么。

## 第二周，工作从哪里继续

到了第二周，这些意见还在不在？上周没查清的问题，它会继续查，还是又交一份从头搜来的报告？

如果又得从头交代，重复的准备工作仍然留给了你。这时才能看清，自己希望它接着完成哪一段工作。
