# SurviAGI 公众号视觉标准

2026-11-03 用户明确将本期视觉固定为公众号标准。技能入口为 [视觉模板](editorial-design.md)。这是公众号品类的应用规范，正文背景、Logo 和绿色强调按本模块执行；课程、短视频与其他品牌品类继续使用原有入口。

**视觉已固定，文风待调整。** 本期法律 AI 文章只保留为视觉参考，不是已认可的文风范例；后续写作反馈进入 [写作模板](writing-guide.md)，不反向重做本视觉标准。

## Logo 与配色

唯一默认生产文件：[`assets/surviagi-horizontal-en-light.png`](../assets/editorial/surviagi-horizontal-en-light.png)，对应无损源为[同款 SVG](../assets/editorial/surviagi-horizontal-en-light.svg)。资产逐字节来自用户已选的 `Feyn-SurviAGI-C-brand-kit-20261030.zip` 浅色环境透明横标，SHA-256 与原始路径见[清单](../assets/editorial/asset-manifest.json)。后续不再从某篇文章的临时 assets 目录猜选 Logo。

- 原始 f. 图形、绿色圆点、C 版圆润英文字标保持完整，不重排、不改色、不裁切、不拉伸。
- 公众号用母品牌 SurviAGI。Feyn OS 为产品身份，不能替换文章母品牌署名。
- Logo 位于正文之后、文字署名之前，居中，300px 宽、max-width:100%、等比显示，无底框；上边距32px。
- 近黑 `#141413` 用于章标、细框和局部分组；品牌绿 `#347B40` 用于目录小题、导读左线与小标；浅绿 `#82C38C` 用于重点线和深底小标。
- 预览白底 `#FFFFFF`，导出的正文容器背景透明，由微信承载。`#F3F2EE` 是原素材画布/反白应用色，不铺满公众号正文、目录或导读。
- 正文 `#333333`，标题 `#202120`；图注 `#777777`。这些中性色是阅读层级选择，不宣称来自 Logo。署名及参考资料使用 `signature.json` 的 `#6E6F69`。

## 固定排版细节

| 角色 | 标准 |
| --- | --- |
| 原生标题 | 由微信标题字段承载；本地仅模拟22px/31px、600字重；正文不再放一遍 |
| 目录 | 白底/透明、1px近黑框、12px圆角；15px/26px；内边距18px 20px 14px；下间距26px；按实际章节生成 |
| 导读 | 直接使用首个文字段落，仅出现一次；3px品牌绿左线；左内边距16px；下间距24px |
| 章节 | 近黑圆角数字章标，14px/21px；H2为24px/35px、700字重；1px近黑上分隔线；上间距42px、线上内距22px、章头下间距26px |
| 正文 | PingFang SC与系统回退，17px/30px、400字重；段后22px；左对齐 |
| 重点 | 按文章内容选择加粗，600字重；3px浅绿下划线；短重点保持完整，长句自然换行；不把整段套高亮 |
| 周讯重点项 | 13px/22px分类/产品小标，23px/34px重点标题；分组数量由实际内容决定 |
| 周讯分组 | 近黑局部标题块、12px圆角、16px 18px内边距；组名20px/30px反白，小标12px/20px浅绿 |
| 周讯短题 | 18px/29px、650字重；开放排布，正文不套整张卡片 |
| 图片 | 宽100%、高度auto、12px圆角；图块上22px下28px；保持原比例，不挤压画面 |
| 图注/日期 | 14px/22px中性灰；图注距图8px |
| 正文左右 | 手机预览20px；桌面阅读区最大677px；导出无固定内容宽度 |
| 署名/来源 | 从 `assets/editorial/signature.json` 与转换器读取；全文完整中英文品牌名加粗；署名及条目12px/1.8，参考标题14px |

正文单栏、内联CSS，不依赖 flex/grid、脚本或远程字体。圆润字形只延续于原字标及短数字章标，正文保持可读。目录、图片数量、章节数量、参考条数、分组数量与字数都随内容变化；不固定法律AI样本的七章、三幅内容图或21条来源。周讯为可选栏目，普通主题文章不强行追加。

## 生成与验证

从稿件生成：

```bash
node scripts/render.mjs /path/to/article.md --date YYYY-MM-DD
```

参数和可选 frontmatter 见技能。转换先走既有 `wechat-api/scripts/md2wechat.mjs --no-cite`，再应用本标准，预览与上传HTML来自同一次渲染；固定 Logo 会校验哈希，复制进当篇输出目录。渲染不触发远端写入。

检查320/390px的目录、章头断行、完整重点、周讯与署名；封面另看2.35:1、1:1及200/96px缩略图。草稿提交继续走 `wechat-api` 全链并回读，本地渲染与微信原生验收分别记录。

## 视觉参考与文风状态

源仓库 `surviving-ai/design/brand-v1/wechat/reference/` 保存当时草稿回读的首屏、主文、周讯和文末截图；本技能不依赖这些历史截图。它们中的文字、数字、访谈标题、客户故事不进入通用模板，也不构成文风通过。

最初借鉴的外部公众号只提供目录、导读、章节、重点字的层级参考。其配色、PART标签、大块浅青标题与灰底未成为本标准。源文章位于 `docs/surviagi-weekly-261102/`，已存公众号草稿；此次标准固化没有覆盖远端草稿。
